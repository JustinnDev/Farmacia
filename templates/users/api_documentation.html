Gestión de Productos

GET Listar Productos
/api/products/

Retorna todos los productos de tu farmacia con su información completa.

POST Crear Producto
/api/products/
Campo Tipo Requerido Descripción
name string Sí Nombre del producto
price decimal Sí Precio en USD
stock_quantity integer Sí Cantidad en inventario
description string No Descripción detallada
requires_prescription boolean No Requiere receta médica
PUT Actualizar Producto
/api/products/{id}/

Actualiza la información de un producto existente. Solo envía los campos que deseas modificar.

DELETE Eliminar Producto
/api/products/{id}/

Elimina un producto de tu inventario.

Gestión de Órdenes

GET Listar Órdenes
/api/orders/

Obtén todas las órdenes de tu farmacia con detalles completos.

PATCH Confirmar Orden
/api/orders/{id}/confirm/

Confirma una orden pagada y reduce automáticamente el stock de los productos.

Importante: Solo funciona con órdenes en estado 'paid'. El stock se descuenta automáticamente.
PATCH Actualizar Estado
/api/orders/{id}/

Cambia el estado de una orden.

Estados válidos: confirmed, preparing, ready_for_delivery

Ejemplos de Código

Python con requests
import requests # Configurar headers con token headers = {'Authorization': 'Token TU_TOKEN'} # Listar productos response = requests.get('https://tu-dominio.com/api/products/', headers=headers) productos = response.json() # Crear producto nuevo_producto = { 'name': 'Paracetamol 500mg', 'price': '5.99', 'stock_quantity': 100, 'description': 'Analgésico y antipirético' } response = requests.post('https://tu-dominio.com/api/products/', json=nuevo_producto, headers=headers) # Confirmar orden response = requests.patch('https://tu-dominio.com/api/orders/123/confirm/', headers=headers)
cURL
# Listar productos curl -H "Authorization: Token TU_TOKEN" \ https://tu-dominio.com/api/products/ # Crear producto curl -X POST \ -H "Authorization: Token TU_TOKEN" \ -H "Content-Type: application/json" \ -d '{"name":"Paracetamol","price":"5.99","stock_quantity":100}' \ https://tu-dominio.com/api/products/ # Confirmar orden curl -X PATCH \ -H "Authorization: Token TU_TOKEN" \ https://tu-dominio.com/api/orders/123/confirm/
